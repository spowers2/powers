## Public path

1. `pnpm create powers my-app` → [GETTING_STARTED.md](./GETTING_STARTED.md)
2. [lab206.com/lab](https://lab206.com/lab?recipe=hello) — hello · form · tokens
3. [lab206.com/system](https://lab206.com/system) — components
4. Flagship product demo: [designlab206.com](https://designlab206.com/)

Designer path: System → [LEARN.md](./LEARN.md) (10 min) → Figma **Powers UI Kit**.

```bash
pnpm create powers my-app
```
