# Powers — what we sell (offer sheet)

**Positioning (one sentence):**  
Powers is a **product UI system** — Figma library + `@lab206/ui` — for people who design and ship real apps. It is **not** a Squarespace-style website builder.

---

## Who it’s for

| Buyer | What they want | What they pay for |
|---|---|---|
| **Freelancer / indie** | Ship client dashboards, portals, ops tools fast | Free under BSL for normal app work; optional commercial if they need an invoice |
| **Agency / studio** | Consistent UI + Figma → code across projects | Studio commercial license; Pro kit when available |
| **Product team** | Design system that matches production components | Studio / Enterprise commercial; Pro Figma pack (later) |
| **Public sector / contractor** | Product UI for portals and internal tools | Commercial license + Pro kit later; see [GOVERNMENT.md](./GOVERNMENT.md) |
| **Competing kit vendor** | Fork Powers into their own UI product | **Commercial license required** (BSL Competing Offering) |

## Free vs paid

- Learn from Lab / demos / docs · `pnpm create powers my-app`
