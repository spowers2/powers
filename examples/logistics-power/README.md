# Logistics Power

Sci-fi freight **control tower** demo for Powers — dense KPIs, shipment matrix, exception bus, partner mesh.

Not Hearth (hospitality) and not designlab206 (studio). Built on the **app-starter** spine.

```bash
pnpm --filter @lab206/logistics-power dev
# → http://localhost:5182
```

lab206 deploy path: `/logistics/` (see `docs/DEMO_LOGISTICS_POWER.md`).
