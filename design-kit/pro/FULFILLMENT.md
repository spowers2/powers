# Powers Pro — sale fulfillment

Manual path until a storefront exists. **Do not promise LemonSqueezy/Gumroad in customer email.** Inquire: [lab206.com/contact](https://lab206.com/contact?subject=Powers%20Pro).

Figma invites must use the **Lab206 / Scott Powers** account that owns **Powers UI Kit** — not a client’s business seat.

## Per sale

1. Confirm payment (invoice / transfer) and buyer email.
2. Build the zip: `pnpm design-kit:pro:pack` → `design-kit/pro/dist/powers-pro-design-kit-*.zip`
3. Email the zip + [LICENSE-PRO.md](./LICENSE-PRO.md) + this pack’s [pack/README.md](./pack/README.md).
4. Duplicate **Powers UI Kit** (or Pro Patterns file) → invite buyer **view** (or the seat they named).
5. If they bought Code Connect / Dev Mode snippets: they already live in the public repo; no extra file unless a private library copy is part of the deal.
6. Log date, email, SKU (Pro $149 indicative / commercial tier) in your sales notes — not in git.
7. Reply with: enable **Powers UI Kit** in Assets · do not detach instances · `pnpm create powers` for code.

## Not in this loop

- Connecting Cursor to a customer’s Figma org
- Publishing Code Connect from a personal throwaway file
- Hosting their production app
