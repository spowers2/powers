# Pro pattern pack

Compose **only** from Powers UI Kit instances + Variables.  
Free Community patterns cover Sign in / Settings row / Confirm. Pro adds product screens.

| ID | File | Use |
|----|------|-----|
| auth-signin | `auth-signin.md` | Sign-in |
| auth-signup | `auth-signup.md` | Sign-up |
| auth-forgot | `auth-forgot.md` | Reset password |
| settings | `settings.md` | Settings hub |
| admin-list | `admin-list.md` | Filterable table / admin list |
| billing | `billing.md` | Invoices / billing summary |
| dashboard | `dashboard.md` | Stats + activity |
| empty | `empty.md` | Empty / error / loading shells |

## Rules

1. Every control is a **kit instance** (Button, Field, Input, …).  
2. Spacing from Variables (`space/*`).  
3. No one-off hex — use color Variables or Pro theme tokens.  
4. Max content width notes are suggestions for Frame constraints.
