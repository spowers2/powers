# Pattern · Empty / error / loading shells

## Empty

| Layer | Component |
|-------|-----------|
| Icon / mark | Text or Avatar placeholder |
| Title | Empty title |
| Description | Empty description |
| CTA | Button solid or soft |

## Error

Alert danger · Text · Button “Retry”

## Loading

Spinner + Text muted **or** Skeleton blocks matching final layout (prefer Skeleton for lists).
