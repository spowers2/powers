# @lab206/dom

DOM + JSX runtime for [Powers](https://lab206.com) — `mount`, control flow, reactive props.

```bash
pnpm create powers my-app
# or
pnpm add @lab206/core @lab206/dom @lab206/ui
```

Set `jsxImportSource` to `@lab206/dom` in Vite / TypeScript.
