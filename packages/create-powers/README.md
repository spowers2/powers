# create-powers

Scaffold a minimal [Powers](https://lab206.com) + Vite app.

```bash
pnpm create powers my-app
# or
npm create powers@latest my-app
```

```bash
cd my-app
pnpm install
pnpm dev   # → http://localhost:5190
```

Installs `@lab206/core`, `@lab206/dom`, and `@lab206/ui` (**^0.1.4**).  
Vite is preconfigured with `jsxImportSource: "@lab206/dom"` (no React).
