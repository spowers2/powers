# Commercial licensing (Powers)

The core monorepo is licensed under the **Business Source License 1.1** ([LICENSE](./LICENSE)).

That is **source-available**, not OSI “open source.” You can read the code; production use is allowed **except** for a **Competing Offering** (shipping a competing general-purpose UI kit / design system based on Powers).

## Free under BSL (no payment)

You may, free of charge:

- Build apps, client work, and internal tools **with** Powers  
- Modify Powers for your own products (not as a competing kit)  
- Run demos and learn from the source  

## When you need a commercial license

Buy (or request) a commercial license if you want to:

- Offer a **competing UI framework / component library / design system** based on Powers  
- Host a rebranded “Powers-as-a-service” kit marketplace or playground that substitutes for the official project  
- Redistribute Powers under terms that conflict with BSL  
- Get a **warranty, indemnity, or priority support** for your company
